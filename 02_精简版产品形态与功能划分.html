一、形态边界：保留什么、放弃什么

边界内容与招标条目的关系
保留席位登录（分析师/复核人）、多路素材导入登记（视频/音频/近红外/毫米波）、离线批分析（逐素材分片进度 + 会话层融合）、六类异常结果 + 三级归因、跨模态因果链、报告起草/审批/发布、审计留痕、CSV/HTML 导出与打印28.01—28.07 的承载主体全部保留
放弃实时监看（LiveConsole）、现场采集端（平板/外勤手机）、呼叫处置队列、值守大屏、分析师手机、后台配置终端、终端协同台、标注复核页均为完整版自行加码的协同/实时能力，无一来自招标原文
接入但封顶近红外（fNIRS）、毫米波两类扩展生理信号，按采样序列文件级导入参与登记、切片与报告；结论只到生理趋势层，不进升级、不出心理归因28.01 "不限于……单一或多种信号的输入"的开放面；封顶理由与逐条失效判据见 06_多信号源上传与硬件接入说明.md §三
不做上述扩展信号的硬件在线接入、驱动、采样级时钟同步与个体基线标定属后续硬件接入项；接入形态与候选信号源见 06_多信号源上传与硬件接入说明.md §四
不承诺<2s/<3s 端到端时延、毫秒级告警、硬件形态随实时能力一并放弃；离线口径改为"分析时长"指标（见第四节）

为什么这样切：① 28.08 实测考察的是"行为异常检测能力"，不是实时性；② 调研证明"上传→分析→报告"是已被市场验证的最小闭环（Dynamics 365、CallMiner、云心测、一心心智同构）；③ 离线形态在 ASR/diarization/时序窗三个环节有可引文献的精度优势（调研报告 §3.2）。

M1 素材上传与会话（任务台）

  • 画面：会话列表 + 统计卡（离线分析中 / 分析完成 / 待审批报告）+「新建会话」导入表单（四个登记框：主信号 视频/音频 + 扩展信号 近红外/毫米波，扩展框标"可选"）。
  • 功能点：按信号源分框选择文件（音视频读容器元数据取时长，采样序列读首列推时基与行数；本机登记，不上传内容）；音视频为主、扩展信号多选非必填，但登记后每一份都进入批分析；授权文书号必填（服务端 403 CONSENT_REQUIRED 卡口，R1）；导入会话与历史会话分源展示（来源列：离线导入 · N 份 + 逐份文件名 + 含扩展信号 标签，后者为只读历史）；同一路信号允许多个文件，按 文件名+类型 去重。
  • 服务端契约：POST /v1/sessions（source:'imported' + assets[{name,size_bytes,duration_seconds,kind:video|audio|nir|mmwave}]）；GET /v1/sessions。
  • 实现锚点：prototype-lite/src/terminals/workstation/SessionsPage.tsx（AssetUpload / probeDuration / probeSeries）
  • 验收：缺文书号建会话被 403 拒绝；未登记任何素材时起批 422；音频素材会话的视觉/生理模态标"不可用"而非 0 值；四路素材会话的已登记列表显示主/扩展计数与每份时长。

M2 分析过程（离线批分析）

  • 画面：任务台行内进度标签（64% · 〔nir_hbo_152s.csv〕运动伪迹剔），结果页顶部为逐素材分片进度清单（✓/▶/· 三态，每段步骤名带文件名），完成后变为「查看结果」。
  • 管线：主信号每份素材 5—6 段（分帧解包 → 语音特征 eGeMAPS → 语义话题/影响值 → 视觉 AU/姿态/手部 → 生理 rPPG），扩展信号每份 4 段（读序列 → 通道配对与光程归一 → 运动伪迹剔除 → 基线校正与切片），最后 1 段为会话层融合 + 判定；进度经 WS 广播（/v1/analysis/stream?channel=workstation）。
  • 功能点：归档只读会话不可发起（409）；批分析进行中重复起批被 409 ANALYZING 拦下（不并发生成第二份报告）；产物只落在本会话，报告口径强制"离线导入 · 非实时"；判定链只在最宽的主素材上跑一次，会话不因多份音视频素材而把同一段对话算两遍。
  • 服务端契约：POST /v1/sessions/:id/analyze-offline（返回 stages/assets/slices/report_id）；WS 事件 offline_progress / anomaly / impact / dialogue。
  • 实现锚点：prototype-lite/mock/engine.ts（analyzeOffline() / runOfflinePass() / offlineStages()）、OfflineResultPage.tsx
  • 验收：四路素材会话返回 20 段进度、4 片切片；可用性与素材类型一致（视频 6/6，音频 2/6，扩展信号 1/6 且仅趋势层）；全程无假 0 值。

M3 分析结果（异常 + 归因）

  • 画面：结果概览卡（登记素材 N / 全部参与、上报异常、其中扩展信号、覆盖模态类数、裁撤条目、话题边界、峰值灯）、素材切片卡区、六类信号可用性行（✓ / ✕ / 仅趋势三态）、异常事件表（含「素材」列）、话题切分与语义影响值区、归因抽屉、跨模态因果链抽屉。
  • 功能点：
    • 每份素材一张切片卡：角色（进全链判定 / 只到生理趋势层）、大小与时基、解析切片清单、该素材可解析/不可解析模态、支撑事件跳转、质量与降级原因；扩展信号另附生理趋势表（基线→峰值→峰值时刻→末段值 + 轨迹）与"本路为什么只到趋势层"逐条列示；
    • 六类异常逐类可命中（28.04/28.07）：语音特征、言语表达、面部表情、身体姿态、手部动作、生理指标（rPPG-HRV）；
    • 分角色识别：逐句 diar_confidence 三态（ok/degraded/off）+ <0.80 告警（28.02）；
    • 话题提取：边界判定依据（句嵌入余弦跳变 + 实体集切换双判据）随话题下发（28.02）；
    • 影响值：四维 0.2情绪冲击+0.3认知冲突+0.3利益相关+0.2持续影响，必带 rationale_text，[0,1] 相对量不可跨会话比较（28.02）；
    • 三级归因：L1 观察层（物理量+单位+时间窗）→ L2 候选规则（权重+文献+命中态）→ L3 结论（置信度+反事实+"模型推断非临床诊断"免责）（28.01/28.03/28.04）；
    • 扩展信号封顶：候选规则层恒为空、严重度上限 ALERT（不触发 ESCALATED）、结论层写"不做心理归因"、confidence 重定义为趋势显著性折算值，并在同屏给出该路的现场判据（头动占比 / 体动幅度）；
    • 单模态输入自动裁剪模态集并显性标注缺失（28.05/28.06）；仅扩展信号时脚本判定链整体裁撤并逐条给原因，不以"检测正常"形式出现；
    • CSV 导出结果台账（含 asset 列、trend_only（不出归因） 标记与全部被裁撤条目）。
  • 实现锚点：OfflineResultPage.tsx（SliceCard / Spark）、src/components/attribution.tsx、mock/script.ts（19 轮对话时间轴 + 7 条异常含 ESCALATED + EXT_SIGNALS 两路扩展信号定义）
  • 验收：npm run verify A/C/D 组断言（六类全覆盖、生理异常触发、分离三态、规则热更新影响结论）+ F/F2 组 21 条（切片数==登记数、扩展事件不出归因不升级、承载素材可追溯、仅扩展信号时判定链裁撤）。

M4 分析报告

  • 画面：报告列表 + 状态机步骤条（起草 → 待审批 → 通过/驳回 → 已发布）+ 审批意见 + 导出（HTML 件 / 打印存 PDF）+ 「精度受限」提示块。
  • 功能点：批分析完成后自动起草报告，六章结构（素材与分析概况 / 素材切片与各自贡献 / 异常行为事件 / 可解释归因与心理原因 / 话题切分与语义影响值 / 局限与免责）；「精度受限」块由素材构成自动生成——列出扩展信号份数、封顶口径、与视频 rPPG 不可互为校验的原因、被降级素材及其触发判据；分析师起草不能自批（角色互斥，服务端校验）；驳回必填理由；缺「局限与免责」章节提交被 422 拦下；发布导出留痕入审计链，导出件含附表 A · 素材切片一览与附表 B 审批流水，未发布件带水印。
  • 服务端契约：POST /v1/reports、/reports/:id/submit|approve|reject|publish|export；审计 seq/prev_hash/sha256 链。
  • 实现锚点：ReportsPage.tsx、mock/engine.ts（draftOfflineReport() / reportHtml()）
  • 验收：verify E 组断言（导出 BOM、哈希链复算、越权 403）+ F 组（报告含章节二且逐份列文件名、导出 HTML 含附表 A 与"离线导入 · 非实时"）。

六、已知限制（如实申报）

  1. 原型无真实推理，结果来自演示脚本（19 轮对话、合成素材 public/assets/demo-talk.mp4；多信号源演示用 public/demo/ 下四路真实格式素材）；
  2. 规则库 8 条脚本候选规则 + R-PSY-22 文献为占位，投标截止前替换为调研报告 §3.1 真实文献或标"待审"；
  3. 近红外/毫米波为文件级导入：无硬件在线接入、无采样级时钟同步、无个体基线标定，结论封顶在生理趋势层（口径见 06_多信号源上传与硬件接入说明.md §三）；扩展信号显著性判据（升幅 >12% 且末段 6/10 窗维持 60%）与 confidence 重定义属自定义口径，出处目录标 C 级，不引文献；脑电/皮电/眼动等不采用（理由见该篇 §四 C 组）；
  4. 影响值 [0,1] 为相对量，不可跨会话比较；
  5. 精简版不含实时监看与跨终端协同——若需求方实测环节明确要求"边采集边看"，回到完整版六终端路线演示（两版同源，数据契约一致）。

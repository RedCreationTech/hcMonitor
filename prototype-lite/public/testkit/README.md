# 测试素材清单（testkit）

配套文档：`../../07_精简版验证操作手册.md`。这里 13 个文件全部由本机生成，供验证时逐份拖进「新建会话」的四个登记框。

生成方式：音视频用 `public/demo/` 下的 156s 谈话样例派生（ffmpeg 重编码，画面与声音都是真谈话）；采样序列由 `../../scripts/gen-testkit-series.mjs` 生成（固定种子，重跑逐字节一致）。
所有 mp4/m4a 都做了 `-movflags +faststart`，moov 前移，浏览器才能在本机秒读时长。

| `V1_谈话室正面_音视频_156s.mp4` | h264 960×720 25fps + aac 96k | 156.0s | 3.1 MB | C1 / C3 / C4 | 单路视频六路模态齐（语音·语义·表情·姿态·手部·生理 rPPG），主链路基线件 |

## 边界件（4 份，故意让登记"读不出来"）

| 文件 | 大小 | 用在哪个用例 | 期望现象 |
|---|---|---|---|
| `X1_短素材边界件_音视频_40s.mp4` | 444 KB | 手册附录 | 素材时长 40s < 脚本时间轴 152s：会话时长取"最长素材"，事件时间戳仍按脚本 0—152s 下发，两者口径不同须看清 |
| `X2_边界_首列为物理量_无时间轴.csv` | 3.3 KB | N5 | 首列是 HbO 浓度（末值 −0.148），落在 10—7200s 判据之外 → 界面显示"时基未读出" |
| `X3_边界_超4MB采样序列.csv` | 6.0 MB | N5 | 超过 `probeSeries` 的 4 MB 上限 → 整体不解析，显示"时基未读出" |
| `X4_边界_JSON采样序列.json` | 15 KB | N7 | 本版按分隔符文本解析首列，JSON 结构读不出 → 显示"时基未读出"（如实限制，见手册第七章） |

> 命名规则：`V` 视频、`A` 音频、`E` 扩展信号正例、`X` 边界件；文件名里的时长与采样率与文件实际内容一致，`ffprobe` / `wc -l` 可复核。
> 素材内容本身不影响分析结果——原型的判定来自演示脚本回放（D 级演示占位），这些文件的作用是**验证登记、切片、融合、报告这条链路在多信号源下是否成立**。

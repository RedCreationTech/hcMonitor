# 「言心」MindDialogue · 精简版工作台（prototype-lite）

需求编号 7008111111 ·《基于对话内容的行为异常检测和心理变化分析技术》
本项目是完整版 `标书/prototype/` 的**精简派生**（仅代码同源，运行与产物零依赖、零写入外部目录）：只保留分析工作台，功能收敛为一条离线闭环——

> **多信号源素材上传分析 → 分析过程（逐素材切片）→ 分析结果（会话级融合）→ 分析报告（可下载打印）**

原项目文件一律未改动；精简版作为独立新项目存在于 `精简版/prototype-lite/`。

## 与完整版的差异

| 保留 | 移除 |
|---|---|
| 任务台 · 素材分析（SessionsPage：一次登记 1—4 份素材、建会话、发起离线分析） | 现场壳 · 谈话室平板（实时采集端） |
| 离线批分析过程与结果（OfflineResultPage：逐素材分阶段进度、素材切片卡、异常列表、三级归因、跨模态因果链、CSV 导出） | 外勤手机 · 形态 D |
| 分析报告与审批（ReportsPage：起草 → 提交 → 审批/驳回 → 发布导出；报告含附表 A 素材切片一览，支持下载与打印） | 值守视图（只读大屏） |
| 席位登录（analyst / reviewer 占席）与审计留痕、WS 事件流、mock 回放引擎 | 分析师手机终端、后台配置终端 |
| | 演示控制坞（原型辅助层；回放引擎的 `/demo/*` 端点仍在 mock 中，仅不再有 UI 入口）、实时监看 LiveConsole、呼叫处置队列、标注复核页、终端协同台、终端总览 |

被删页面的**服务端能力仍在 mock 中存在**（`/annotations`、`/tickets` 等 REST 端点未拆），
只是精简版 UI 不再提供入口——正式实现时后端可按同一契约收缩，不影响数据链路。

## 运行

```bash
npm install
npm run dev        # http://127.0.0.1:5185 （固定端口，避开完整版 5175）
npm run build      # tsc -b && vite build，已验证通过
npm run verify     # 需 dev server 运行；49 条断言，指向 5185
npm run demo-multi # 用 public/demo 的四份真实文件跑一遍完整批分析，打印会话号与结果页地址
```

> `npm run verify` 与 `demo-multi` 共用同一个内存引擎，**不要并发跑**（两套断言会互相污染出假失败）。

演示动线（约 3 分钟）：
1. 打开首页 → 席位登录（分析师 W-02，PIN `1234`）；
2. 任务台点「新建会话」：填对象编号 / 场景 / 授权文书号，在四个登记区分别拖入
   `public/demo/` 下的录像（mp4）、录音（m4a）、近红外（csv）、毫米波（csv）——
   音视频为主，扩展信号可多选且非必填，但**登记进来的每一份都参与分析**；
   （种子会话 `SES-2026-1017-V31` 是**已归档**的录像 + 毫米波导出表样例，只能看列表与报告口径；
   归档只读，行内「离线分析」为禁用态，起批会被服务端 409 拦下——该卡口见验证手册用例 N8。要跑链路请新建会话）
3. 行内按素材逐段推进（视频 6 步 / 音频 5 步 / 近红外·毫米波各 4 步，末了 1 步会话级融合，WS 广播）→ 点「查看结果」；
4. 结果页先看汇总与模态可用性，再逐张看素材切片；点开任一异常查三级归因
   （观察层 → 规则+文献 → 结论层含反事实与免责）；扩展信号事件只有趋势层：候选规则为空、最高 ALERT、标「离线导入 · 非实时」；
5. 「分析报告与审批」：基于结果起草 → 提交 → 复核人席位（R-01）审批 → 发布，导出 HTML 可下载/打印，
   附表 A 逐份列出素材文件名。

## 口径红线（沿用完整版）

- 心理原因一律为**模型推断**，非临床诊断；结论必带反事实与免责声明。
- 本版为脚本回放原型，无真实推理；量化指标只允许「文献参考水平 / 实测现场标定」两类标签。
- 近红外、毫米波按**采样序列文件级**接入（读一行算一行，不解码、不上传内容）：所有登记素材都进分析、都出切片，
  但结论封顶在生理趋势层——不进升级、不出心理归因，自定义口径 C 级；硬件在线接入、时钟同步与个体标定属后续项（接口契约见 `../06_多信号源上传与硬件接入说明.md`）。

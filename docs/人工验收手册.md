## 已知边界（验收时请按此口径评判）

| 边界 | 说明 |
|---|---|
| 样例音视频为 TTS 合成 | 声学层事件偏密（合成音 jitter/音调特征异于真人）；真人采集后明显正常 |
| 微表情 | 学术 SOTA F1 仅 0.41-0.45，本系统只做「AU 闪现」检测并低置信呈现，不承诺 MER |
| NLI 矛盾 | 矛盾分 ≥0.5 才放行，且文案明示需人工核验；与事实矛盾不等同 |
| rPPG | 合成样例上 20/38 窗心率带外（伪迹），已质量门降级；真人固定机位复测更准 |
| 手部动作 | 冷启动几何规则，需自标注迭代分类器（方案文档 §11） |

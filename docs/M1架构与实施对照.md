## 2. C4 上下文

系统服务于局域网内的采集员、分析师、指定复核人、报告接收人和项目/审计管理人员。浏览器只访问同源应用；模型、媒体、报告和数据库在本机服务器运行。互联网仅在操作员显式准备依赖/模型包时使用，运行时不解析在线模型仓库。

## 5. 关键状态与不可变边界

- 素材：登记 → 分块上传 → 全文件hash/格式预检 → 封存。不能用元数据代替上传成功。
- 作业：queued → running → succeeded/partial/failed/cancelled/interrupted。租约丢失后旧执行者不能提交；失败不生成成功报告。
- 修订：revision N → 校正草稿保存 → revision N+1、旧结果stale → 新run。已完成run、原文与报告快照不覆盖。
- 复核：行为决定与解释决定独立，附理由并追加记录；改动送审后的复核决定会阻断沿用旧批准。
- 报告：drafting → pending_review → approved → published；驳回后可改，批准/发布后另建版本。版本号在会话范围内递增。
- Grant与Export：授权不是文件；生成成功ready后仍须重新校验领取权限。撤回用途、禁用账号、授权到期/撤销均阻断新领取。
